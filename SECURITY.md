---

## Reporting a Vulnerability

We take the security of Corral-Lite and its consumers seriously. If you discover a security vulnerability or potential exposure:

1. **Do NOT report security vulnerabilities via public GitHub issues, discussions, or pull requests.**
2. Please send a detailed report directly via email to:
   **`natthaphong.yingratpinyo@gmail.com`**
3. Include as much diagnostic information as possible:
   - A clear description of the vulnerability and affected component.
   - Minimal proof-of-concept (PoC) code or reproduction steps.
   - Potential impact or attack vectors.
   - Your proposed remediation or patch, if available.

---

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours of receipt.
- **Triage & Assessment**: Within 5 business days with status updates.
- **Fix & Disclosure**: We will collaborate with you to release a patch and coordinate public disclosure in a responsible manner.
